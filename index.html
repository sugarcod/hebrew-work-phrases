Фразы на работе на иврите

Полная версия с озвучкой и текстами — это самодостаточный HTML-файл (~3 МБ).

Чтобы сделать этот репозиторий доступным онлайн:

  1. Зайди в этот репозиторий → Settings → Pages
  2. В Source выбери Deploy from a branch
  3. Branch: main, папка: / (root)
  4. Нажми Save

Через 1–2 минуты появится ссылка:
https://sugarcod.github.io/hebrew-work-phrases/

Полный файл с аудио можно скачать из чата и открыть локально.
